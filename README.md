# ForceLocoManipulation

G1 humanoid locomotion and object-manipulation experiments.

## Lift retargeting

See **[retargeting/lift](retargeting/lift/README.md)** for the OMOMO-to-G1 workflow, complete HOI contact commands, generation scripts, diagnostic evidence and the lift-only artifact uploader.

The documented selection contains 24 exported lift candidates: 6 smallbox, 13 plasticbox and 5 largebox. Hand-contact correction and dynamic grasp validation remain pending. The code/evidence are included; the generated motion files and previews must be collected from the laptop using the uploader.

Existing T1 selection and policy-curve files are retained. This lift handoff does not replace policy checkpoints or claim the candidate references are training-ready.
